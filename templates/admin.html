常见问题
401 或 403：检查中转 API Key 是否正确且已启用。
Token 不可用：重新登录 ChatGPT，在 Token 管理中重新导入登录状态。
模型不存在：确认模型已在“模型管理”中添加并启用。
连接失败：确认客户端填写的是完整 API Base URL，并保留末尾的 /v1。
